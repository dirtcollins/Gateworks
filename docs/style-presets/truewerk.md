# Truewerk Style Preset

Saved on branch `codex/truewerk-style`.

This preset keeps the Phase 1 product system behavior from the Home Depot baseline and changes the visual layer toward Truewerk's product-page direction:

- Warm off-white page background with black, charcoal, muted gray, and utility green accents.
- Avenir/Helvetica-style sans font stack for a cleaner apparel/workwear feel.
- Truewerk-inspired top navigation with promo bar, centered wordmark, and `Men`, `Women`, `Gear`, `Workwear System`, `Mission`.
- Product page CTAs use black primary buttons with a green confirmation fill animation.
- Recommendation rail cards use compact `+ ADD` buttons that add directly to cart without navigating.
