# Home Depot Style Baseline

Saved baseline for the Phase 1 product page system.

This preset captures the current Home Depot-inspired ecommerce UI:

- Black and orange retail header
- 588px desktop PDP purchase column
- Product image gallery with thumbnails
- Variant buttons for real product options only
- One-column stacked PDP buy box
- Closed-by-default details accordions
- Home Depot-style related/recently viewed carousel rails
- Carousel category tabs, scroll buttons, compact cards, and dark hover Add to Cart buttons
- Add-to-cart feedback animations on rail buttons, PDP buttons, and header cart badge
- High-resolution National Hardware product images

Use this as the stable reference before creating alternate CSS/layout options.
